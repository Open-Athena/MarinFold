How to read these comparisons

Individual maps have different numbers of contacts. We therefore report full-map F1 = 2 × correct / (predicted + true), together with precision and recall. A map with only a few correct contacts cannot score perfectly on F1. The pooled top-R map has R predictions and R true contacts, so its F1 equals canonical R-precision.

Oracle means the best map chosen using the known truth. It measures available sample quality and is not a deployable selection method. Independent-pool consensus selects a sample from pool A (100 maps) by its mean Jaccard similarity to pool B (another 100). Summary metrics average the swapped A/B roles; the inspector shows the A-selected map. The likelihood selector uses mean generated-token log probability. Both selectors use no truth.

Cluster voting groups one pool by whole-map Jaccard distance using average linkage (k=2 or 4), then assigns the opposite pool to the learned medoids. Votes are pooled within clusters with ≥10 independent assigned samples. We report both selection of the largest training cluster and the truth-oracle best cluster. These are contact-map comparisons, not tests of 3D physical feasibility.

Truth and the resolved-residue universe are identical to the original contact-map atlas: pyconfind degree ≥0.001 and sequence separation ≥6, input-sequence coordinates, unknown residues masked. No eval-test proteins were analyzed.

Provenance and reproducibility

The 200 samples use temperature 1.0, top-p 0.95, disabled top-k, fresh document realizations and token budget min(8192 − prompt length, 6L + 128). The exact checkpoint export, tokenizer, source ETags, code hashes, per-input timings, sample seeds and complete raw maps are preserved. The first protein passed serialization and completeness checks before the same loaded model continued through the full set.

Original aggregate contact-map report · Experiment issue · Public report, raw samples and tables

Large oracle gains would show that better contact maps exist in this finite sample. Small gains would show a sample-quality limitation under this recipe and budget, not that no decoder could ever recover the correct fold. Neither result alone identifies a training cause.
